PROJECT

What is this system?

This academic prototype applies YOLO object detection to agricultural images. Instead of only classifying an image, it locates individual crop and weed objects with bounding boxes and confidence scores.

USE CASES

Where can it be used?

Field scouting, crop monitoring, early weed identification, selective spraying support, and classroom demonstrations of AI-based precision agriculture.

MODEL

What is measured?

Each prediction includes the detected class, confidence score, and bounding-box coordinates. The dashboard summarizes crop and weed counts for the uploaded image.
